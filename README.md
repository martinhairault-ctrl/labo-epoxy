# Le Labo d’Époxy : refonte de la page d’accueil

Maquette de refonte de [lelabodepoxy.fr](https://lelabodepoxy.fr) (Next.js App Router + TypeScript).

```bash
npm install
npm run dev
```

- Contenu (offre, prix, avis, FAQ, liens) : `lib/data.ts`
- Une section par composant : `components/`
- Styles et tokens de la marque : `app/globals.css`
- Photos réelles du site, optimisées : `public/img/`

Le stock, les prix et les dates d’atelier sont figés au 14/10/2026 ; les boutons pointent vers les fiches du site WooCommerce existant.
